Latest review · 30 October 2026 · checked 12:07 UTC

OpenAI canceled the Pro 200 usage cut. Public tests still show no broad model decline.

OpenAI canceled its planned Pro 200 Work and Codex allowance reduction on 29 October, one day before the announced cutoff. Public tests checked today do not establish a broad capability decline. They do surface narrower evidence: a resolved GPT-6.1 Sol API performance incident and an ABIS behavior-change signal for Gemini 3.5 Flash.

Current call: broad capability decline is not established. A change in access can feel like a model change, but OpenAI canceled the planned Pro 200 Work/Codex reduction on 29 October. Check your current account allowance before changing plans.

Before you switch

If a request stopped or an allowance ran out, save the error, selected model, surface, and plan display, then check the current plan terms and provider status. If a completed answer missed a task, repeat a safe task with the same model selection, effort, context, and settings. Track correctness, conversation fit, completion, correction time, and usage separately.
