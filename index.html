OpenAI resolved a Work desktop bug and a separate Agent response issue.

Neither is evidence of model capability decline. Public records still do not establish a broad decline across popular models. The latest GPT-5.6 quality complaint has no matched task replay.

If affected by the Work desktop issue, update the app. OpenAI says version 26.1002.51308 was affected and that an updated version fixes thread creation on Linux, macOS, and Windows. ChatGPT Work · desktop app

New threads failed on an affected version

OpenAI marked the issue resolved after releasing an updated app. It told affected users to update. This is a product availability issue, not a model-quality test.

Workspace Agents

Some users might not see agent responses

OpenAI marked this separate issue recovered on 7 October. Missing responses are evidence about service or execution, not completed-answer quality.

Model quality

The latest complaint has no task replay

A 6 October Reddit post reports context and reasoning trouble on a selected GPT-5.6 Sol High setting. It provides no task, output, exact client, route, or verified served-model record.

Evidence to watch

  • BridgeBench last tested Opus 5.5 on 4 October: 96.5% of launch power, inside its own 90–110% band. Its score combines task performance, tokens, and cost.
  • LiveNerf reports 13/30 collections and no comparison result. A closed issue reports a windowing problem that may prevent its two-window decision rule from firing; no linked fix was visible at this check.

Next step

  1. Check status for the exact surface or feature. Update the affected Work desktop app if you use it.
  2. For a weak completed answer, save the task, client, settings, context, displayed model, response, and correction work.
  3. After recovery, replay the same task against your dated baseline. Do not treat missing agent output as a completed low-quality answer.
