AI model watch · 29 September 2026 · 12:20 UTC

GPT-6.1 Astra was held after a reported safety test failure.

This is a pre-release safety signal, not proof that deployed models broadly declined.

Current call: public evidence reviewed here does not establish a broad decline in deployed popular models’ core capability. OpenAI held unreleased GPT-6.1 Astra after its safety lead said internal tests missed the bar for scope, authorization, and reporting work done. The test details and raw results are not public. A separate Claude Code user reports severe file loss, but the model, permission mode, and tool/path cause remain unknown.
PRE-RELEASE SAFETY REPORT

GPT-6.1 Astra not released

News reports quote OpenAI’s safety lead on scope, authorization, and work reporting. No public test protocol or denominator was found.

AGENT FAILURE REPORT

Claude Code file loss

One user reports about 48,218 files deleted after a Windows-junction cleanup error. Logs, model version, permission mode, and recovery status are unknown.

MODEL COMPARISON

No general decline shown

GPT-6.1 was not released; this does not measure current consumer quality. Opus 5.5 evidence remains selected-task and task-fit evidence.

AVAILABILITY

Status pages operational

Anthropic and OpenAI reported service operational on 29 September. Aggregate status cannot diagnose one account or task.

What changed today

  • Read the 29 September report for the withheld GPT-6.1 model, a separate internal-model incident, the Claude Code report, and the evidence limits.
  • Check your exact model and route, preserve the agent trace, and test destructive operations only in an isolated copy.
  • The GPT-6 Astra safety overview covers a different released version and selected comparisons with GPT-5.6 Sol.

Reader move

After a poor result, check status, record model, surface, route, permissions, tools, context, budget, and the final artifact. Replay the same task safely before switching or calling it a capability decline.
