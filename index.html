AI model watch · 26 September 2026 · 12:00 UTC

No broad decline proven. The evidence splits by task and system.

Bug Hunt reports a negative GPT-6 Sol coding slice. Braintrust reports a near-tie on 175 API examples. OpenAI records a resolved Codex outage. These findings answer different questions.

Current call: no broad cross-model core-capability decline is proven. Treat the coding result as a task-specific lead. Retry or wait after an incident, then replay a fixed task before switching.
NEGATIVE SLICE
29.3 / 105

Bug Hunt maximum mean for GPT-6 Sol, versus 43.5 for GPT-5.6 Sol. Small runs, wide spread, context and harness caveats.

COUNTERWEIGHT
76.8% / 77.2%

Braintrust reports GPT-6 Sol and GPT-5.6 Sol nearly tied across 175 API examples. GPT-6 Luna is 78.0%.

AVAILABILITY
56 min

OpenAI records a full Codex outage across Web, API, CLI, and VS Code on 25 September, recovered at 23:54 UTC.

What changed

  • Read the dated report for the benchmark limits, incident timeline, allowance split, and replay plan.
  • Bug Hunt Bench is a cross-sectional agent benchmark, not a time series.
  • Braintrust is a separate API evaluation with a different task mix, effort, judge, and outcome.

Reader move

During a declared incident, retry or wait. Then replay one fixed task with the surface, release boundary, served identity, route, effort, tools, context, budget, judge, run count, artifact, correction burden, and control recorded.
