Before you switch models

  1. Check the provider’s status page for the exact time and product surface.
  2. Save the failed request, response, task artifact, and visible model and plan.
  3. After recovery, replay the same task with the same settings and compare it with a saved baseline.

A failed request or missing page is not a valid capability test. A completed but worse answer needs a task-level comparison.

What is still open

OpenAI had not published its promised root-cause analysis at the latest check. The status records do not identify a shared cause between providers, report account-level error rates, or measure model quality after recovery. There is no representative sample or repeated consumer-task time series showing broad capability decline.

Earlier reports about GPT-6.1 Astra’s pre-release safety hold and one Claude Code file-loss incident remain separate safety and agent-risk signals. They do not change this capability verdict. See the 29 September safety and file-loss report.
