Current call · 24 October 2026

Broad AI-model decline is not established.

The new Claude Code report gives a concrete task-level lead, but it is one uncontrolled account. Anthropic’s status timeline adds service events—not proof about completed answers. ChatGPT state and refusal reports remain separate leads.

Before you switch: Save the output or exact error and check the provider timeline. For a poor completed answer, replay a safe synthetic task after recovery with model, client, effort, context, and compaction state recorded. Change one variable at a time.
