Match the test to the symptom

For a blocked or failed request, preserve the exact error and check the provider timeline. For a completed but poor answer, repeat a safe task with the same prompt, model snapshot, surface, context, and settings. For a safety change, define the boundary and review the answer under a consistent rubric. Count correction time and task completion separately from exact-match scores.
