Reader move

When the failure looks like #44851, preserve the task and artifact, record requested and served model separately, capture capacity and route state, replay with the same context and effort, and run a control. When it looks like a status incident, retry or wait. When the meter moves without a completed artifact, call it an economics or access problem until the ledger says more.
