Community reports · 22 October 2026

Conversation lockouts are not completed-answer tests.

Users describe “Chat memory full” notices that stopped sending; some later report recovery. OpenAI also documented separate service events. None of these records establishes a broad model capability decline.

Fresh ChatGPT reports: a blocked send

An OpenAI Community user report describes a warning after about 10–14 messages; a reply says it affected three software-development chats and that clearing saved Memory did not help that account. Another user says the warning appeared and disappeared intermittently. These are user reports, not a provider diagnosis or prevalence measure.

Some Reddit users later said their chats worked again. One 22 October post reports normal sending for one free account after more than 200 messages. Other users describe ongoing or cross-device differences, so a global fix is not established. A Spanish-language account compares app builds on different phones and accounts; it cannot isolate app version as the cause.

Provider records show separate service events

OpenAI marked a 20 October ChatGPT, Codex, and API degraded-performance incident recovered. Its separate 21–22 October Conversations/Responses API incident affected India, Japan, and Korea and was also marked recovered. Neither record links to the memory-full notice or confirms an individual account’s recovery.

Keep saved memory and conversation access separate

OpenAI’s Memory documentation distinguishes saved memories from information referenced through chat history. It does not explain the reported send-blocking warning. A banner that prevents a new message is an access/continuity symptom; a completed answer that loses context needs a different test.

Other recent evidence

The 21 October review covers reports of poorer memory and generic answers alongside OpenAI’s Chat versus Work/Codex release boundary. The 20 October review compares BridgeBench and LiveNerf tracker results and methods.

For a blocked task, save the work, note date, region, surface, app/client build, plan, and exact message, then check the provider status window. For a completed weak answer, replay the same safe task with model, settings, tools, context, and scoring recorded.
